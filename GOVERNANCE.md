# Governance

ProteinClaw uses a single-maintainer governance model for the initial public
Codex plugin release.

## Maintainer

Daanish Hindustani is the project maintainer and final decision maker for
technical direction, releases, repository policy, and contribution acceptance.

## Decision Making

The maintainer will prefer simple, tested changes that preserve the Codex plugin
contract and avoid unnecessary operational complexity. Community input is
welcome through issues and pull requests, but final decisions rest with the
maintainer.

## Maintainer Responsibilities

- Review and merge pull requests.
- Maintain release notes and plugin metadata.
- Triage bugs, security reports, and compatibility issues.
- Keep generated artifacts and local runtime state out of the repository.
- Protect the project from unsafe or misleading scientific claims.

## Future Maintainers

If the project gains regular contributors, the maintainer may add maintainers or
move to a maintainer council. That change should be documented in this file.
